# VIN Gallery

یک سایت ساده برای:
- جستجوی عمومی موتر با VIN
- نمایش مشخصات موتر
- نمایش گالری عکس‌های متصل به VIN
- پنل ساده برای ثبت موتر و آپلود عکس

## راه‌اندازی رایگان

این نسخه برای میزبانی استاتیک ساخته شده و می‌توانید آن را روی GitHub Pages / Cloudflare Pages / Netlify قرار دهید. برای دیتابیس و ذخیره عکس از Supabase استفاده می‌کند.

### 1) ساخت Supabase
به https://supabase.com بروید، یک پروژه بسازید.
در SQL Editor محتوای `schema.sql` را اجرا کنید.

### 2) کلیدها
در Supabase از Project Settings > API مقدار:
- Project URL
- anon public key
را بردارید.

در `index.html` و `admin.html` این دو مقدار را جایگزین کنید:
YOUR_SUPABASE_URL
YOUR_SUPABASE_ANON_KEY

### 3) امنیت پنل
برای استفاده واقعی، `admin.html` را عمومی نگذارید یا آن را پشت احراز هویت/Cloudflare Access قرار دهید. در Supabase نیز سیاست‌های Storage را فقط برای کاربران authenticated تنظیم کنید.

### 4) استفاده
- `index.html`: صفحه عمومی جستجوی VIN
- `admin.html`: پنل ثبت موتر و آپلود عکس
- VIN را وارد کنید، موتر را ذخیره کنید، سپس عکس‌ها را با همان VIN آپلود کنید.
- هر شخص می‌تواند VIN را در صفحه اصلی وارد کند و عکس‌های عمومی را ببیند.

نمونه VIN:
JTEBU14R350060840

## نکته
این سایت دیتابیس مستقل خودش است؛ یعنی عکس‌های شما به‌طور خودکار وارد CARFAX، NICB یا دیتابیس‌های دیگر نمی‌شوند. برای اینکه عکس‌ها در سایت خود شما با جستجوی VIN پیدا شوند، همین معماری مناسب است.
